# Project provenance and usage

This portfolio develops a University of Queensland BISM7233 teaching case about bank loan default. It is an academic analysis, not a commercial engagement or a deployed credit decision system. No university endorsement is implied.

The supplied dataset and teaching documents retain their original ownership and terms. They are not distributed in this public repository. Power BI files are also withheld because they embed the dataset. A local, ignored `private/source/` folder retains the supplied originals. No repository-wide licence is asserted over third-party case material.

The original RapidMiner process files and selected embedded screenshots from the completed assignment report are included as project evidence. Extracted DAX, calculated columns and report metadata preserve the original logic. The extracted Power Query replaces the original computer path with `CsvPath`; a separately named portable adaptation is a portfolio addition. Report screenshots show historical native outputs; this portfolio review does not claim a fresh native execution.

Repository organisation, English and Traditional Chinese documentation, read-only code extraction, aggregate checks, visual design maps, Python verification and artificial fixtures were prepared with AI assistance in October 2026. They are separate from the original assignment. Historical authorship is not inferred from filenames or course templates.

This repository is a later portfolio presentation of the supplied work. The original report narrative, historical screenshots and subsequent technical review are distinguished in the evidence register. No grade or production-deployment claim is made.
